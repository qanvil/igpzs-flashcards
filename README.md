# ИГПЗС Flashcards

Мобильный тренажёр флеш-карточек по глоссарию ИГПЗС.

## Что внутри

- 141 карточка из исходного документа
- термины и определения без ручного сокращения
- переворот карточки по нажатию
- свайп влево/вправо на телефоне
- поиск
- фильтр по разделам
- отметка «выучил»
- сохранение прогресса в браузере
